# 동영상 변환기 (MP4)

AVI · WMV · MKV · MOV · ASF 파일을 MP4(H.264 + AAC)로 바꿔 주는 Windows용 프로그램입니다.
변환 엔진은 ffmpeg이며 실행파일 안에 들어 있어서 따로 설치할 것이 없습니다.

## 다운로드

설치 없이 쓰는 실행파일은 [Releases](https://github.com/wooryihwang/video-converter/releases) 페이지에서 `VideoConverter.exe`를 내려받으면 됩니다. (저장소 안에서 직접 빌드하면 `dist\동영상변환기.exe`로 만들어집니다.)

## 사용법

1. `dist\동영상변환기.exe`를 실행합니다. (처음 켤 때 몇 초 걸립니다. 실행파일 안의 변환 엔진을 푸는 시간입니다.)
2. **[파일 추가…]** 또는 **[폴더 추가…]**로 동영상을 목록에 넣습니다. 파일을 목록 위에 끌어다 놓아도 됩니다.
   - 폴더를 추가하면 하위 폴더까지 뒤져서 지원 형식만 골라 넣습니다.
3. 변환 설정을 고릅니다.
   - **품질**
     - 원본 그대로: 영상·소리 코덱이 MP4에 맞으면(H.264/HEVC/MPEG-4 + AAC/MP3 등) 다시 압축하지 않고 통만 바꿉니다. 화질 손실이 없고 몇 초 만에 끝납니다. WMV·ASF처럼 MP4에 못 담는 코덱이면 자동으로 재인코딩합니다.
     - 고화질 / 표준(권장) / 작게: H.264로 다시 압축합니다. 아래로 갈수록 파일이 작아지고 화질이 조금 떨어집니다.
   - **크기**: 원본 크기 그대로 두거나 1080p·720p·480p로 줄입니다. 원본이 더 작으면 키우지 않습니다. (크기를 고르면 항상 재인코딩합니다.)
   - **저장 위치**: 원본 파일과 같은 폴더, 또는 지정한 폴더.
   - **덮어쓰기**: 끄면 같은 이름이 있을 때 `이름 (1).mp4`로 저장합니다.
4. **[변환 시작]**을 누릅니다. 줄마다 진행률이 표시되고, 아래 막대는 전체 진행률입니다.
   - **[중지]**를 누르면 현재 파일을 중단하고 만들다 만 파일은 지웁니다.
   - 실패한 줄을 두 번 누르면 이유를 보여 줍니다. 완료된 줄을 두 번 누르면 저장된 파일을 탐색기에서 보여 줍니다.

## 실행파일 다시 만들기

Python 3.12와 아래 패키지가 필요합니다.

```
pip install pyinstaller imageio-ffmpeg tkinterdnd2
```

그다음 `빌드.bat`를 실행하면 `dist\동영상변환기.exe`가 만들어집니다.
(`ffmpeg.exe`가 폴더에 없으면 imageio-ffmpeg 패키지에 들어 있는 것을 복사해 씁니다.)

## 파일 구성

| 파일 | 설명 |
|---|---|
| `video_converter.py` | 프로그램 본체 (Python + tkinter) |
| `ffmpeg.exe` | 변환 엔진 (ffmpeg 7.1, 빌드할 때 exe 안에 포함) |
| `빌드.bat` | 실행파일 만들기 |
| `dist\동영상변환기.exe` | 배포용 실행파일 |

Python이 설치된 컴퓨터에서는 `python video_converter.py`로 바로 실행할 수도 있습니다.
